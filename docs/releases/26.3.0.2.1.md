## Tag

`26.3.0.2.1`

## Release title

EnchantmentDescriptions 26.3.0.2.1：修复客户端提示框崩溃

## Release notes

此版本基于上游 EnchantmentDescriptions 26.3.0.2，面向 Minecraft 26.3 的 Fabric 客户端。

### 修复

- 修复查看某些物品时，追加按键提示会导致客户端崩溃的问题。
- 保留隐藏物品提示的行为，避免向原本为空的提示列表添加文字。
- 保留原有提示内容和顺序，避免修改调用方的原列表。

### 构建与文档

- 新增 Fork 版本配置和 Windows 构建入口，统一生成 `26.3.0.2.1` 版本产物。
- 更新 Fork 的项目链接、构建说明和简体中文 README。
- 将模组的下载入口指向本 Fork，移除 NeoForge 元数据中的上游更新检查地址。
- 构建时自动生成本地版本徽章，并校验产物版本号。

### 安装

关闭客户端，用本版本的 Fabric jar 替换原有 EnchantmentDescriptions 文件，并保留与你的客户端版本匹配的 Prickle 依赖。修复后可以继续使用按键查看附魔说明和按键提示功能。
